# Better Hitbox Trail

Better Hitbox Trail adds an in-game settings popup for a more customizable hitbox trail.

## Usage

Press H to open the menu. You can customize opacity, color, and thickness for each hitbox and game mode in the Geode settings page.

## Features

- Hitbox Trail
- Show on Death
- Always Show
- Only Player
- Only Cube
- Only Click and Release
- Square Hitbox
- Blue Hitbox
- Circle Hitbox
- Rotation Hitbox
- Trail Length
- Opacity
- Thickness
- Color Clicks
- ...and more

All popup settings take effect immediately, even while paused.

Shows hitboxes for actual sub-tick click timings under CBF/CBS. Can be disabled in Geode settings.

Automatically displays hitbox trails when **Show Hitbox** is enabled in other mod menus (QOLMod, MegaHack, Eclipse).

## Notes

Please turn off any built-in **Hitbox Trail** feature in other mod menus to prevent overlap.

If you also use MegaHack, turn off **Player** under MegaHack's Show Hitboxes sub-settings.

Eclipse and QOLMod both show the player hitbox whenever their Show Hitboxes setting is enabled, and there's no way to turn off just that part.

## Known Issues

- Even if MegaHack's Show Hitboxes is enabled, Better Hitbox Trail may automatically disable itself if MegaHack has no hitboxes of its own to display on screen.
